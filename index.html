News Headline Search

Search the headlines of 325 million news articles back to October 2019. Data is sourced from GDELT.

More information

The GDELT project extracts geolocated event data from millions of news articles over time and makes the resulting data available for download. Beginning in 2019, this data includes the headline (but not the body) of each article. These headlines alone are a rich and entertaining source of information about global attention, and this website makes it possible to quickly search these headlines for words or strings, then chart the result. Please explore the filters below, which make it possible to group articles by source, compare term searches to each other, and share direct links to interesting findings. You can also read the articles (as long as the original source’s link still lives) by following the result links. Please also see the source code for this project, which was “vibecoded”.

A headline counts for one “article” every time it appears whatsoever, regardless of previous appearances globally or for a given source.
