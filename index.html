Headline Search

Every headline in the GDELT Global Knowledge Graph since October 2019, English-language files, about half a billion of them. Word search matches whole words, in any order. Substring search matches the exact run of characters, so zelensk finds both spellings. Case does not matter.


Data is GDELT's, ingested a few times a day, so the last day is always incomplete. Headlines are page titles as GDELT recorded them, site name suffix and all. Source.
